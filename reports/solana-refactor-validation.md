## Exercised behavior

The Solana integration test loads the actual `.so` into a disposable, voting local validator. It builds two deltas with the real manager, registers their Space, sends both transactions, waits for finalized state, independently verifies exact transaction/Receipt data through the real HTTP API, and checks two SQLite rows became anchored. It then reconciles the same records without their transaction signatures and rejects a different transition at an already occupied sequence. Temporary wallets, validator and ledger are removed on completion.

Rust execution tests cover missing/wrong signatures, separate payer/authorizer, incorrect PDA/owner, gaps and incorrect previous roots, zero commitments, permission rotation/replayed nonce, overflow, duplicate initialization/receipt and atomic rollback after failure. JavaScript codecs are cross-checked against bytes generated by Anchor serialization.

Persistence/API/CLI regressions cover durable migration, index rebuild, old v1 witnesses, v2 digest ambiguity removal, a single card snapshot, concurrent builders, orphan witnesses, partial identity rejection, workspace lifecycle/races, fabricated transaction confirmations, empty queues, and configuration updates during RPC checks.

## Reproduction

Build and run Rust/SBF checks using `contracts/solana/README.md`. Then set these paths for a full Node run:

```sh
export AWARENESS_ANVIL_BIN=/absolute/path/to/anvil
export AWARENESS_SOLANA_TEST_VALIDATOR=/absolute/path/to/solana-test-validator
export AWARENESS_SOLANA_PROGRAM_SO="$PWD/contracts/solana/target/deploy/awareness_memory.so"
node --test --test-timeout=240000 test/*.test.mjs
```

For the focused suite, use `npm run test:anchoring`. Without the corresponding tool paths, the two chain integration tests explicitly skip. The local validator startup waits for finalized slot 32 to avoid Agave's early genesis program visibility delay.

Verified toolchain: Node 22.23.2, web3.js 1.98.4, host Rust 1.90.0, Anchor 0.32.2, Agave 3.0.13, platform-tools v1.52/SBF Rust 1.89.0, LiteSVM 0.7.1.
